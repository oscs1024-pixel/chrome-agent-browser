SEC.01

加载 Chrome 本地解压扩展

01

打开扩展管理页

在日常使用的 Chrome 地址栏输入下述地址并回车，然后开启页面右上角的「开发者模式」开关。

chrome://extensions
02

加载本地扩展目录

点击左上角的「加载已解压的扩展程序」，选择本项目工程根目录下的 extension 文件夹。

chrome-agent-browser extension --reveal
03

固定图标并验证连通

点击 Chrome 工具栏右上角的拼图图标将 chrome-agent-browser 钉出，然后终端运行体检命令验证链路。

chrome-agent-browser doctor
SEC.02

运行实景与受控解构

清晰受控，一目了然

当 Agent 开始接管并操作你的浏览器时，页面将通过多重视觉线索保持透明，你随时清楚当前哪一页有主、由谁在控、正在执行什么。

  • 1
    同色 Chrome 标签组

    多个 Agent 并发时自动按会话分配专属色彩与标签组，杜绝串页与误操作。

  • 2
    页内同色动态描边

    页面外围带有同色高亮边框与定位圆点，操作点位置实时可见。

  • 3
    右下角控制驾驶舱

    实时显示当前步骤、执行进度与会话短码，随时可暂停或断开。

  • 4
    截图幕帘保护 (Stealth Mode)

    Agent 在截屏时，页面自动在瞬间隐去边框与驾驶舱，确保大模型获取真实洁净视图，绝不产生视觉幻觉。

附录与疑难排解

扩展显示离线（Chrome 扩展这会儿没连着桥）怎么办？
1. 确保 Chrome 浏览器已启动。
2. 检查 chrome://extensions 页面中 chrome-agent-browser 扩展是否已开启。
3. 点击浏览器工具栏的 chrome-agent-browser 图标，在弹出的窗口中点击「重连」按钮。
4. 重新在终端执行 node src/cli.js doctor 检查即可恢复。
什么时候需要开启「高保真模式（L2）」？
默认情况下扩展使用轻量级合成事件（L1），无调试条闪烁。当遇到需要校验物理点击（isTrusted: true）的强反爬站点、Monaco/CodeMirror 富文本编辑器或需要截取后台非置顶标签页时，点击工具栏 chrome-agent-browser 图标开启「高保真模式」即可一劳永逸。
如何配合 Pi Agent 等本地 Coding Agent 使用？
运行 chrome-agent-browser install 后，将自动在 ~/.pi/agent/extensions/chrome-agent-browser.ts 配置好原生 agent_browser 工具。
在 Pi Agent 中直接对话即可调用日常 Chrome，亦可通过 MCP 标准服务接入 Claude Code、Cursor 与 Codex。
